# 🌐 Pritam Thopate – Portfolio Linktree

Welcome to my personal **Linktree-style portfolio** built using **Next.js** and **Tailwind CSS**. This project serves as a clean and animated landing page to share my social links, built with modern web technologies and hosted on [Vercel](https://vercel.com/).

## 🔗 Live Demo

👉 [Click here to view live](linktree-git-main-pritam-thopate.vercel.app)  

---

## ✨ Features

- Splash screen with animated name and tagline
- Smooth fade-in transitions using Animate.css
- Responsive design
- GitHub, LinkedIn, and Instagram links
- Hosted on Vercel for fast performance

## 🛠️ Local Setup

1. Clone this repo  
   ```bash
   git clone https://github.com/pritam-t/portfolio-linktree.git
   cd portfolio-linktree


2. Install dependencies

bash:
npm install


3. Run the development server

bash:
npm run dev

4. Open http://localhost:3000 in your browser to see the result.
